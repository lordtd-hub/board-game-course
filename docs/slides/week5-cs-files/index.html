  • เสียโอกาสรอ Scene tile รอบถัดไป
  • เสียโอกาสฟัง presentation ของคนอื่น

ประโยคถามหน้าห้อง

“ข้อมูลตอนนี้พอคุ้มกับการใช้สิทธิ์เดาครั้งเดียวหรือยัง?”

Marginal Utility

เบาะแสใหม่มีค่าเพิ่มเท่าไร?

ค่าสูง

เบาะแสใหม่ตัดตัวเลือกออกไปได้หลายใบ หรือแยกผู้ต้องสงสัยสองคนออกจากกัน

ค่ากลาง

ช่วยยืนยันสมมติฐานเดิม แต่ยังไม่ทำให้กล้าใช้ Badge

ค่าต่ำ

ซ้ำกับสิ่งที่รู้อยู่แล้ว หรือกว้างเกินจนตัดอะไรไม่ได้

cheap talk / credibility

คำพูดฟรี แต่ความน่าเชื่อถือมีต้นทุน

ผู้เล่นพูดอะไรก็ได้ แต่ถ้าพูดโดยไม่มีหลักฐานหรือเปลี่ยนเรื่องบ่อย ความน่าเชื่อถือจะลดลง และกลายเป็นทรัพยากรที่ใช้ต่อรองยากขึ้น

คนร้ายไม่ได้ต้องชนะด้วยการพูดเก่งอย่างเดียว แค่ทำให้ทรัพยากรการคิดของโต๊ะถูกใช้ผิดทางก็พอ

Externality

การพูดของเรากระทบทรัพยากรของคนอื่น

ผลดีต่อโต๊ะ

จัดกลุ่มหลักฐานให้คนอื่นเห็นภาพ, ช่วยตัดตัวเลือก, ตั้งคำถามที่ตรวจสอบได้

ผลเสียต่อโต๊ะ

ลาก discussion ไปไกล, ชี้เป้าแบบไม่มีหลักฐาน, ทำให้คนอื่นใช้ Badge ผิดจังหวะ

นี่คือเหตุผลที่ C.S. Files เป็นเกมสอน “ทรัพยากรของกลุ่ม” ได้ดีมาก
